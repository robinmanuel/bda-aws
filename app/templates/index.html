How It Works

  1. VPC Isolation: The EC2 server lives in the public subnet to receive web traffic, while RDS resides safely in the private subnet without internet exposure.
  2. Zero Exposed DB: Only requests originating from the EC2 security group can query the database.
  3. Credential-less S3: EC2 uses AWS IAM Instance Profiles to upload photos without saving any secret keys on the server.
