AWS 3-Tier Security Architecture

This Personal Diary demonstrates defense-in-depth on AWS using VPC isolation, IAM instance profiles, and strict Security Group rules:

1
Public Subnet & EC2:

The Flask application runs on an EC2 instance inside the VPC Public Subnet. Inbound HTTP traffic (port 80) is accepted via the Internet Gateway (IGW).

2
Private Subnet & RDS:

The MySQL database lives in a Private Subnet with no Internet Gateway route and no public IP. Inbound MySQL traffic (port 3306) is locked specifically to DiaryApp-EC2-SG. Public internet cannot connect directly to RDS.

3
IAM Instance Profile & S3:

The EC2 instance uses an attached AWS IAM Role to upload and retrieve photos from an S3 bucket with Block Public Access enabled. Temporary presigned URLs are generated for viewing, avoiding exposed API keys.
